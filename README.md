# Sales Data Analysis & Visualization (Power BI)

## 📊 Opis projektu
Kompleksowa analiza danych sprzedażowych oparta na modelu hurtowni danych. Celem projektu było przetworzenie surowych danych, stworzenie relacyjnego modelu oraz zaprojektowanie interaktywnego dashboardu biznesowego wspomagającego podejmowanie decyzji.

## 🛠 Kluczowe elementy projektu
* **Modelowanie danych:** Implementacja architektury **Schematu Gwiazdy (Star Schema)**.
* **Integracja tabel:** Połączenie tabeli faktów (SALES_FACT - 2.8 mln rekordów) z tabelami wymiarów (CUSTOMERS, PRODUCTS, TIMES, CHANNELS).
* **Analiza biznesowa:** Wyliczenie kluczowych wskaźników efektywności (KPI) takich jak Revenue, Units Sold oraz liczba zamówień.
* **Wizualizacja:** Stworzenie interaktywnego dashboardu z podziałem na trendy czasowe, kategorie produktów oraz geografię sprzedaży.

## 📈 Funkcje Dashboardu
* Analiza przychodów w czasie (Revenue by Month).
* Rankingi Top 5 produktów i klientów.
* Segmentacja przychodów według poziomu wykształcenia klientów i departamentów.
* Zaawansowane filtrowanie danych.

## 🔧 Technologie
* Power BI Desktop
* Modelowanie relacyjne (Star Schema)
* DAX (podstawowe miary i kolumny obliczeniowe)
